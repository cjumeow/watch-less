# yt-digest

A button on a YouTube thumbnail turns the video into a neutral, evidence-backed summary in Heptabase, so the developer
can decide from the summary whether the video is worth watching.

## Language

**Digest**:
The neutral, evidence-backed summary of one video, in the sections the digest prompt defines.
_Avoid_: summary note, report

More terms are added here as the spec decides them, with `domain-modeling`.
